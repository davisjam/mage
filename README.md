# MAGE — Model-Based Agentic Software Engineering

The research-program site for MAGE, part of the
[James C. Davis / Duality Lab](https://davisjam.github.io/) research portfolio.

Engineering software when implementation is abundant but judgment remains
scarce. Published at <https://davisjam.github.io/mage/>.

## This is not the MAGE resource site

Two sites, two purposes. This one is the **scholarly front door**: what the
research program is, what questions it studies, what it has produced, who is
involved, and what supports the work.

The canonical MAGE resource environment — the book, the course mirror, the
detailed framework, examples, and adoption guidance — lives at
<https://davisjam.github.io/model-based-agentic-software-engineering/>
and is developed independently.

The editorial test before adding anything here:

> Does this help an evaluator, researcher, prospective student, collaborator,
> or funder understand the MAGE **research program**?

If instead it helps someone **learn, teach, or apply** MAGE, it belongs on the
canonical site. That distinction is an architectural invariant, not an initial
content preference.
